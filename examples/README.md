# Example files

- `demo_commands.sh`: every command used in the video, in order, with comments.
- `scans/`: the saved scan results from the demonstration, created by step 4 (`-oA scans/scanme_baseline`):
  - `scanme_baseline.nmap`: plain-text report
  - `scanme_baseline.xml`: XML for other tools (for example, Metasploit's `db_import`)
  - `scanme_baseline.gnmap`: one line per host, easy to search with `grep`
